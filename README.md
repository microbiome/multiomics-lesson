# Multi-omics lesson

A Carpentries-style lesson on multi-omics microbiome data analysis with
R/Bioconductor. It uses [The Carpentries Workbench][workbench].

The lesson assumes that learners can analyse a single microbiome table, for
example from the
[microbiome lesson](https://github.com/microbiome/microbiome-lesson) or
equivalent experience. It goes through the `MultiAssayExperiment` data container and the
main groups of integration methods: exploratory, unsupervised and supervised.

You can view this lesson at https://microbiome.github.io/multiomics-lesson/

## Status and plans

The lesson is a first draft (pre-alpha). It has five episodes:

1. Introduction to multi-omics
2. MultiAssayExperiment and the study data
3. Exploratory methods
4. Unsupervised methods
5. Supervised methods
6. Summary

The methods episodes will be expanded in the future, for example with more
supervised and Bayesian approaches.
